# Приёмник материалов по игре

Складывай сюда **всё**, что у тебя есть по идее игры из Санта-Круз — в любом виде, без порядка:

- заметки, наброски, мысли (текст, .md, .docx, .txt)
- переписки с другими ИИ про игру
- картинки, скриншоты, мудборды (.png, .jpg)
- pdf, таблицы, презентации
- ссылки (просто вставь их в этот файл списком ниже)

Порядок наводить **не надо** — это твоя задача-ноль, моя задача потом разобрать.

## Как положить файл в VSCode
- Перетащи файл мышкой из Finder прямо в эту папку (`_inbox/game`) в дереве слева.
- Или: правый клик по папке → Reveal in Finder → скопируй туда файлы.

## Когда закончишь
Напиши мне «**готово, разбери инбокс**» — я прочитаю всё, что здесь лежит, и предложу:
1. что это за игра (по твоим материалам),
2. куда её положить в проекте,
3. как организовать документооборот, чтобы не мешало работе над эпизодами.
