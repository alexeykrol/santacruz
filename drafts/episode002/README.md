# Эпизод 002: Поле

## Метаданные
- Номер эпизода: 002
- Название: Поле
- Часть: 1 (Земля)
- Акт: 1 (Аномалия)
- Глава: 1 (Шторм)
- Длина: ~10 155 символов
- Количество сцен: 3
- Статус: Черновик v2

## POV
Полковник (USNORTHCOM) — безымянный, идентифицируется по должности.

## Want / Need / Deserve
| | |
|---|---|
| Want | Взять ситуацию под контроль |
| Need | Принять, что контроль здесь невозможен |
| Deserve | Быть тем, кто называет это вслух — официально, первым |

## Singable phrase
*"Они ушли, потому что дома были целы"*

## Структура (v2 — исправленная физика + цепочка статистов)
- **Сцена 1** — Прибытие (4 сент., 06:14): вертолёт садится внутри купола на сухие улицы, стены воды на всех горизонтах
- **Сцена 2** — Эвакуация (4 сент., 10:15): объявление «радиации», жители уходят из целых домов, ключ в кармане
- **Сцена 3** — Последний борт + Доклад (4 сент., 17:22–18:41): форма DoD 1501, "Other", зачёркнутое "предположительно", Эдди Роу последним

## Физика купола (корректная)
- Долина затоплена снаружи на 5–6 м
- Купол держит воду снаружи — **все внутри**, на сухих улицах
- Смотришь изнутри: стены мутной воды на краях города
- Вход/выход только вертолётом

## Цепочка статистов (три сломанных инструмента)
1. Полковник — нарратив «радиация» vs видимый целый город
2. Житель — ключ в кармане vs непонятно когда вернётся
3. Эдди Роу — вторничная рутина с термосом vs следующего вторника не будет

## Связь с ep001
- Эдди Роу: остался в куполе во время шторма, теперь эвакуируется последним
- Полковник USNORTHCOM: упомянут в ep001, теперь его POV
- Проницаемость: птицы и люди — да, вода — нет (подтверждено дайвером)

## Что устанавливает этот эпизод
- Первое официальное именование: «купол»
- Первое официальное признание: «неприродного происхождения»
- Система знает что делать с кризисами; с этим — нет
- Эвакуация без разрушений: уходят из целых домов
