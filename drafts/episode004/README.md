## Краткое описание

Истекают семьдесят два часа с момента волны. Утром в городе ещё работают окна сопровождаемого доступа — тридцать минут на адрес, чтобы забрать лекарства, документы, животных. К вечеру окон нет, периметр замкнут, город официально стал зоной.

## POV

Марисоль Ортега, координатор Cal OES по сопровождаемому доступу. Опыт CZU 2020.

| | |
|---|---|
| **Want** | Удержать окна доступа — единственное, что осталось от её работы |
| **Need** | Признать, что её функция на этом инциденте невыполнима |
| **Deserve** | Один раз сказать человеку не легенду, а правду |

## Singable phrase

**«Дом стал уликой»** — воплощена физически: житель подаёт заявку на содержимое собственного холодильника, и дом получает номер объекта. В финале первый номер в реестре, `000001`, достаётся не куполу и не артефактам, а этому холодильнику.

## Mood

**Изъятие.** Не паника и не хаос: изымают ключи, доступ, маршрут, право открыть собственную дверь.

## Ключевое ограничение канона

По `development.md` (Событие 2) к 72 часам зона — город-призрак с 25-км периметром; по Событию 3 возврат населения происходит **только через полгода**. Поэтому в эпизоде нет и не может быть возвращения жителей — только окна сопровождаемого доступа, которые в этот день и отменяют.

Ранние черновики (v1, v2) были построены на «отменённом возврате населения» и противоречили канону. Исправлено в v3–v4.
